## 👋 About me

I'm **Mohamed Ashraf** — a software engineer with **8+ years** of hands-on experience in
**project architecture, backend development, and performance optimization**. I currently serve
as **Technical Lead at [Convertedin](https://www.converted.in/)**, where I own technical
decisions for AI-driven SaaS products and build scalable systems that support growth.

My core is **PHP & Laravel**, extended across **Node.js, NestJS, and Symfony** (certified). I care
about clean architecture, maintainable systems, and shipping real value — and I love contributing to
**open source** and mentoring the next generation of developers (former **Web Development Instructor
at AMIT Learning**).

- 🔭 **Now:** leading backend for AI-driven SaaS at Convertedin — **Flyerz**, **ConvertedPay**, and **ConvertedOrders** (which I created): turn any product link into revenue, fully AI-run.

## 📦 Open source

I build and maintain developer tools across **npm** and **Packagist**.

### 🔎 Loupe — pin feedback to the live UI, hand it to Claude

An embeddable visual-feedback platform: inspect any element on a live product, pin a comment,
capture a screenshot; comments **re-anchor across redeploys** and reach **Claude Code via MCP**
as an actionable backlog.

<p>
  <a href="https://www.npmjs.com/package/@loupekit/sdk"><img src="https://img.shields.io/npm/v/@loupekit/sdk?style=flat&logo=npm&color=CB3837&label=%40loupekit%2Fsdk" alt="@loupekit/sdk" /></a>
  <a href="https://www.npmjs.com/package/@loupekit/mcp"><img src="https://img.shields.io/npm/v/@loupekit/mcp?style=flat&logo=npm&color=CB3837&label=%40loupekit%2Fmcp" alt="@loupekit/mcp" /></a>

